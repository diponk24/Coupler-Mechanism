# Coupler Mechanism

This project was developed to study and visualize the synthesis of planar coupler mechanisms. It allows users to generate 4-point and 5-point coupler mechanisms through an interactive interface.

## What's Included?

### 4-Point Coupler Mechanism

#### Graphical Method
- Follow the graphical synthesis procedure step by step.
- Adjust design parameters if required.
- Default optimized values are provided for quick generation of the mechanism.

#### Analytical Method
- Select the required precision points.
- The corresponding coupler mechanism is generated automatically.
- Designed to simplify the synthesis process without manually performing lengthy calculations.

### 5-Point Coupler Mechanism
- Input the required precision points.
- Generate the corresponding coupler mechanism for visualization and analysis.

## Features

- Interactive and easy-to-use interface.
- Automatic mechanism generation.
- Adjustable parameters for experimentation.
- Optimized default settings for quick results.
- Visual representation of the generated mechanisms.

## Motivation

The objective of this project was to better understand mechanism synthesis concepts taught in kinematics and machine design. Instead of carrying out repetitive manual procedures, the project provides a simple way to explore different coupler configurations and observe how changing the input affects the resulting mechanism.

## How to Use

1. Provide the required precision points.
2. Modify the parameters if needed.
3. Generate and study the resulting coupler mechanism.

Developed as part of an academic exploration of planar mechanism synthesis and kinematic design under the course Machines and Mechanisms.
